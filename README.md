# HCA 解码器(如果你没有解码秘钥，你将无法使用此工具)

# 如何解密 HCA 文件

将 HCA 文件拖放到 Main.exe 上，即可解密出同名 WAVE 文件，同时也支持多文件解密。（注意：解密后裔的文件将会覆盖同名文件）

# 参数（修改需编译）

默认解码参数为：

音量 = 1 (x)

位模式 = 16 (位)

循环次数 = 0 (次)

解密密钥 = XXXXXXXXXXXXXXXX (16位)

如果 HCA 文件包含循环信息，则会在 WAVE 文件中添加一个 smpl 数据块。

但如果解码选项中的循环数为 1 或更高，则不会添加 smpl 数据块，而是直接输出波形数据。

[循环起始位置到结束位置] + [循环起始位置到结束位置] × (循环数 - 1) + [循环起始位置到结束位置]

如果 HCA 文件包含注释信息，则会在 WAVE 文件中添加一个注释数据块。

# 注释

目前已禁用版本检查，但未来发布 HCA 2.1 及更高版本时，解码可能会失败。

HCA 文件头损坏检查也已禁用，这样做是为了方便修改文件头，即使文件确实损坏，也不会出现任何错误。

加密表中使用的密钥因游戏而异。（PS：某些开发公司也许会使用相同的密钥。）

当加密表类型为 0x38 时，如果密钥不同，则解码将无法正常工作。使用指定的解密密钥进行解码时，

仅支持 CBR 格式。VBR 格式将无法解码。*VBR 格式可能不存在。

由于命令提示符的限制，包含“&”符号的文件路径（文件名和文件夹名）将无法打开，并且在拖放到 Main.exe 等批处理文件中时会导致错误。
